# برومبت تشغيل صندوق مطبعجي على شات قديم

انسخ الرسالة التالية في **آخر المحادثة القديمة**:

```text
ادخل GitHub وافتح مشروع Matbagy-Design-Workflow على فرع agent/initial-mvp، ثم ادخل على مجلد صندوق_مطبعجي وابدأ بقراءة ملف اقرأني_أولاً.md بالكامل.

بعد ذلك نفذ تعليمات استخراج المحادثات القديمة الموجودة داخل الصندوق على هذه المحادثة الحالية من أول رسالة إلى آخر رسالة متاحة.

استخرج كل Design Case موجودة في الشات، بما يشمل الطلب، النصوص، الصور ودور كل صورة، المقاسات، المراجع، المحاولات، النتائج، تعديلات المستخدم، ما تم رفضه، ما تم قبوله، النتيجة النهائية إن كانت مؤكدة، والقواعد التي يمكن للمصمم الذكي التعلم منها.

مهم جدًا:
لا تسجل أي شيء داخل صندوق مطبعجي الآن.
اعرض لي أولًا Draft كامل طبقًا للـSchema الموجود في الصندوق، وميّز بوضوح أي معلومة INFERRED أو UNKNOWN.
بعد مراجعتي، إذا قلت لك "تمام سجل" أو "اعتمد وسجل"، نفذ تعليمات SAVE_APPROVED_CASE.md وسجل الحالة.
```

## النسخة المختصرة

إذا كان الـAI قادرًا على الوصول إلى GitHub وفهم المرجع بدون تفاصيل إضافية، استخدم:

```text
ادخل GitHub على صندوق مطبعجي داخل Matbagy-Design-Workflow، اقرأ اقرأني_أولاً.md، ثم طبق تعليمات استخراج الشات القديم على المحادثة الحالية كاملة. اعرض Draft فقط ولا تسجل قبل موافقتي.
```
